# Setup your GitHub profile repository

1. Create or open the public repository named exactly `darsh-vaishnav`.
2. Extract this ZIP file.
3. Copy **all** files and folders into the root of that repository.
4. Commit and push the files to the `main` branch.
5. Open the repository's **Settings → Actions → General** and ensure Actions are allowed. Under workflow permissions, allow read and write permissions if the workflow needs them.
6. Open **Actions → Generate contribution snake → Run workflow** once.
7. After the workflow succeeds, the `output` branch will be created. The contribution animation in README will then load.

## Important notes

- The local SVG artwork is in `assets/`; keep the folder and its filenames unchanged.
- The contribution animation is generated by GitHub Actions and published to the `output` branch.
- GitHub statistics, streaks, profile-view and technology icons are served by external services; they are not files in this repository.
- The LinkedIn button currently points to LinkedIn's homepage. Replace it with your real profile URL if you want it to link to your account.
- No email address or personal contact details have been invented.
- The projects listed are based on your previously described work. Edit any description that no longer reflects your contribution.
